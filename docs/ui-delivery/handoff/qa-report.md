# QA 摘要

机器记录以 `qa-evidence.json` 为准。本轮在 macOS 26.5.2 arm64 上完成前端构建、Oxlint、DTCG CSS 同步检查、Playwright 4 项交互测试、axe 自动扫描、Rust fmt/clippy/test、Tauri 原生启动与原生窗口截图。

## 通过范围

- 首屏持续说明扫描不主动修改内容、名称、birthtime 或 mtime，并披露部分文件系统可能更新 atime；变更步骤在 M0 锁定。
- 合成数据流程覆盖 idle → scanning → results，证据脊柱和时间弱证据可见。
- 1280×820 与 1024×768 截图经全尺寸检查，无溢出、空白、敏感信息或模板残留。
- 反模板审阅通过：没有装饰性渐变、玻璃拟态、巨型装饰文字、通用 KPI 卡片墙或与任务无关的营销区块；证据脊柱在扫描和结果态保持可识别。
- 键盘从首个操作进入选择、扫描和结果；axe 在首屏和结果态均返回零 violation。
- 原生 Tauri 窗口成功启动并截图；独立审读确认当前 Rust command 没有变更调用，webview capability 也未开放 fs/shell/http 插件。后者不是 Rust command 的 OS 沙箱保证。
- 扫描核心 24 项测试覆盖 root-fd 相对打开、祖先符号链接置换、换根中断、目录身份防循环、非 UTF-8 路径、默认排除、硬链接、哈希桶逐字节等价类、并发替换、不可读文件、取消与报告序列化。

## 修正记录

首轮界面测试发现侧栏/琥珀文本对比度、可滚动详情焦点和目录选择后的焦点恢复问题，已修正后重新跑通 4/4。安全复核还移除了真实扫描的定时伪进度、补齐 opaque path，并让重复目录身份把报告降级为 partial。数据库独立复核发现未密封计划可错误启动 item，已增加触发器阻断并重新通过完整状态链与非法迁移测试。

## 限制

- 尚未使用 VoiceOver 对中文读序、状态播报和系统目录对话框做人工走查。
- 浏览器 E2E 使用合成报告；原生窗口已验证启动和视觉，但未自动操纵系统目录对话框完成真实移动硬盘扫描。
- 开发构建仍为脚手架应用图标，不能作为发布品牌资产验收。
- 本 QA 只证明 M0 只读里程碑，不证明时间恢复、隔离事务或永久清理功能已经实现。
