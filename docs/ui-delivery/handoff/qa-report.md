# QA 摘要

机器记录以 `qa-evidence.json` 为准。本轮在 macOS 26.5.2 arm64 上完成前端构建、Oxlint、DTCG CSS 同步检查、Playwright 13 项交互测试、axe 自动扫描、Rust fmt/clippy/test、Tauri shell 构建与原生进程启动；当前 Phase 1 原生窗口截图未取得，已明确降级。

## 通过范围

- 首屏持续说明扫描不主动修改内容、名称、birthtime 或 mtime，并披露部分文件系统可能更新 atime；变更步骤在 Phase 1 继续锁定。
- 合成数据流程覆盖 idle → scanning → results 与历史目录 → 封存结果，证据脊柱、时间证据和 display-only 权限边界可见。
- 1280×820 与 1024×768 截图经全尺寸检查；历史目录、分页结果和原始 metadata 展开态均无溢出、敏感信息或模板残留。
- 反模板审阅通过：没有装饰性渐变、玻璃拟态、巨型装饰文字、通用 KPI 卡片墙或与任务无关的营销区块；证据脊柱在扫描和结果态保持可识别。
- 键盘从首个操作进入选择、扫描和结果；axe 在首屏、历史目录、结果与原始字段展开态均返回零 violation。
- Tauri shell/Rust bundle 与最终前端生产构建分别通过；bundle 早于最后一项前端-only result queue 修复且随后按磁盘治理删除，因此不冒充精确最终树集成包。独立审读确认当前 Rust command 没有变更调用，WebView capability 只开放事件 listen/unlisten。当前环境未能重新枚举窗口，因此旧 M0 原生截图不作为 Phase 1 视觉证据，当前视觉由浏览器渲染截图覆盖。
- 扫描核心 59 项测试覆盖 root-fd 相对打开、祖先符号链接置换、换根中断、目录身份防循环、非 UTF-8 路径、默认排除、硬链接、哈希桶逐字节等价类、并发替换、不可读文件、取消、流式背压与不可构造读取证明。

## 修正记录

首轮界面测试发现侧栏/琥珀文本对比度、可滚动详情焦点和目录选择后的焦点恢复问题。后续安全复核还修正了路径字符串授权、结果回执锁死、分页竞态与失败游标、历史 display path 被误画成当前权限、迟到历史响应保留 token、同一 result token 并发单飞冲突，以及 raw Base64/定位范围断层；全量 13/13 重新通过。数据库与桌面端的 reader、token、单实例锁和非法迁移边界由独立 Rust 门禁覆盖。

## 限制

- 尚未使用 VoiceOver 对中文读序、状态播报和系统目录对话框做人工走查。
- 浏览器 E2E 使用合成报告；原生进程已验证启动，但未取得当前窗口视觉证据，也未自动操纵系统目录对话框完成真实移动硬盘扫描。
- 本 QA 证明当前 Phase 1 的只读扫描、封存证据分页与历史复核界面；不证明持久化暂停/续扫、报告导出、隔离事务、时间写回或永久清理已经实现。
