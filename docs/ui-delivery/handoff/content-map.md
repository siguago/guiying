# 内容地图

## 语言与数据边界

主语言为简体中文（zh-CN），方向为 LTR。界面未接入多语言框架；英文仅用于技术状态和哈希缩写。截图、演示报告、路径和照片名全部为合成数据，不含真实照片、GPS 或用户目录内容。

## 核心文案

| 场景 | 主文案 | 约束 |
| --- | --- | --- |
| 首屏 | 先看证据，再决定要不要动文件。 | 强调决策顺序，不承诺自动清理 |
| 权限 | 不主动修改内容、名称、birthtime 或 mtime；读取可能更新 atime | 准确描述当前 command，不宣称 OS 级零写入 |
| 扫描 | 正在建立内容证据 | 不使用“智能识别”模糊算法 |
| 暂停 | 目录枚举已暂停；仅本次打开期间可继续 | 只在枚举安全点生效，不承诺退出或崩溃后的续扫 |
| 继续 | 正在继续目录枚举 | 使用同一进程中仍存活的运行时与目录描述符 |
| 结果 | 发现 N 组确定重复 | 只指完整内容哈希相同且扫描时逐字节确认的组 |
| 时间 | 内嵌拍摄时间证据；文件系统时间独立列示 | 双重提取和封印只供审阅，不自动修复 |
| 历史 | 封存范围文本；当前没有目录权限 | display path 不是可打开路径或 root token |
| 历史时间状态 | 完成 / 部分完成 / 未运行 / 不可用 / 失败 | 五态不互相冒充；非终态时间证据不可见 |
| 历史导出 | 导出封存报告 | 只写用户另选的新报告文件，不修改照片或恢复历史目录权限 |
| 完整重复证据 | 包含摘要、重复组、成员和扫描问题 | 不含拍摄时间候选/成员/元数据记录、原始字段或定位器；摘要可含时间阶段汇总 |
| 导出路径 | 隐去（默认） / 包含显示路径 | 显示路径与问题消息可能包含个人目录名称；不导出原生路径字节或文件权限 |
| 锁定步骤 | 后续里程碑，当前锁定 | 不让用户误以为隔离功能已实现 |

## 错误与恢复

- 空目录或路径无效：要求重新选择目录。
- 扫描失败：未执行移动、改名或改时；允许回到目录选择。底层读取仍可能按卷策略更新 atime。
- 暂停或继续请求失败：保持服务端已确认的阶段，允许重试或停止；迟到响应不能覆盖取消或终态。
- 单文件不可读、损坏或扫描中变化：加入 issues 并保留，不阻断其他安全候选。
- 导出失败或取消：不覆盖已有目标；未发布完成的临时文件由原生层尝试清理，界面不显示目标父目录。
- 浏览器预览：明确使用合成数据，不冒充本地磁盘扫描。

## 换行与截断

标题允许中文自然换行；路径在左侧范围摘要中以省略方式显示，完整值保留在 `title`。重复组文件名允许换行或截断但详情保留完整路径。数值使用中文单位格式，哈希只显示前缀且不作为唯一可见标识。

产品与风险文案以 `docs/product/PRD.md` 和 `docs/engineering/SAFETY.md` 为准；界面文案由 `src/App.tsx` 与 `src/lib/backend.ts` 消费。新增变更能力前必须重新审阅“不主动修改”和“当前锁定”措辞。
