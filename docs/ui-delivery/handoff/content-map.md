# 归影 v0.2 内容地图

主语言为简体中文（zh-CN），LTR。中文是本地化约束，不是传统、档案或复古视觉依据。普通界面优先使用用户动作语言；D1、BLAKE3、descriptor、token、封印等术语只出现在高级证据或诊断中。

## 核心文案

| 场景 | 主文案 | 用户要理解的事实 |
| --- | --- | --- |
| 起点 | 找出重复，保留你想留的那份。 | 先只读扫描；决定和移动是后续显式动作 |
| 扫描 | 正在查找完全相同的文件 | 自动阶段无需操作；可暂停或停止 |
| 结果 | 选择一组，然后决定保留哪份 | 不要求一次处理全部组 |
| 成员 | 保留 / 隔离 | 只有一份 keeper；其他相同副本进入 Move 意图 |
| 计划 | 确认这一组的隔离计划 | 点击执行前不会移动；不永久删除、不改时间 |
| 标准构建 | 真实隔离仍在安全验证中 | 可查看计划，不显示可执行的真实移动承诺 |
| 内部实验 | 重新授权并执行 | 只在双重 internal gate 下使用专用测试卷；不得用于用户照片 |
| 完成 | N 个副本已移入隔离区 | keeper 仍在原位；清单可恢复 |
| 恢复 | 恢复这次隔离 | 原路径冲突时绝不覆盖；部分恢复要明确剩余数 |
| 合成演示 | 合成数据演示只模拟状态，不会访问本地文件 | 演示不能冒充真实照片动作 |
| 高级证据 | 为什么判定为完全相同 | 技术解释按需展开，不阻断主任务 |
| 主导航 | 整理 / 活动（隔离区仅 internal） | 每一项都是可到达的位置，不是开发阶段 |
| 扫描进度 | 已检查 / 待检查 / 已用时 | 算法阶段折叠在「如何确认？」之后 |
| 结果规模 | 共检查 N 个媒体文件，其中 M 个是重复副本，重复占用 X | 数字服务当前决策，不单独成格 |
| 导出 | 导出活动记录（可选） | 报告是次要活动，不等于照片已整理 |

| 不再使用 | 现用 |

## 错误与恢复文案原则

- 说明对象、当前结果和下一步，不只显示错误码。
- 取消系统选择器等同于未授权，不显示失败，也不执行。
- 内容、文件身份、卷或封存证据变化时回到复核；不能用用户确认绕过。
- 隔离部分完成时清单是事实来源；不能把部分完成写成“成功”。
- 恢复冲突时说明安全替代位置；永远不提供覆盖不同内容的选项。
- 扫描读取可能由文件系统更新 atime；归影不主动改名、改照片内容或 birthtime/mtime。

## 换行与截断

标题允许中文自然换行。路径在行内中部/尾部省略并保留完整可访问名称；计划页只显示当前 keeper 的完整上下文。文件名、移动数量和恢复状态不能因截断失去区别。数值使用本地格式；技术哈希只显示前缀且不作唯一可见标识。
